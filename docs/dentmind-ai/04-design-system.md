# 04. Design System

The DentMind AI interface should feel premium, calm, clinical, and futuristic.

## Visual Direction

- Apple-level restraint
- Stripe-grade gradients
- Linear-style dashboard density
- OpenAI-inspired AI interaction patterns
- Notion-like clarity for records and notes

## Themes

Light mode:

- Background: `#f8fafc`
- Surface: `rgba(255,255,255,0.78)`
- Primary text: `#0f172a`
- Secondary text: `#64748b`
- Border: `rgba(148,163,184,0.22)`
- Accent: violet/indigo/cyan gradient

Dark mode:

- Background: `#070812`
- Surface: `rgba(15,23,42,0.72)`
- Primary text: `#f8fafc`
- Secondary text: `#94a3b8`
- Border: `rgba(148,163,184,0.18)`
- Accent: violet/cyan electric glow

## Components

- Glass cards
- Magnetic CTA buttons
- Command menu
- AI chat composer
- Voice waveform
- Upload dropzone
- X-ray viewer frame
- Citation cards
- Source chunk viewer
- Confidence meter
- Skeleton loaders
- Empty states
- Billing plan cards
- Audit log timeline

## Motion Rules

- Default transition: 180ms ease
- Page transition: 260ms ease
- Scroll reveal: subtle translateY 16px
- Reduced motion support required
- AI thinking state: soft pulse, not distracting

## Accessibility

- WCAG AA contrast
- Visible focus rings
- Keyboard navigable dashboard
- Screen-reader labels for icons
- High contrast mode
- Reduced motion media query
